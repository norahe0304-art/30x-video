# scaffold/ - Remotion editable first-cut template
Remotion + TypeScript + Tailwind v4 template for premium launch videos. This directory stays reusable and mode-aware; brand projects consume it, not the other way around.

<directory>
src/ - Composition entry, generated project seam, design tokens, and visual primitives (3子目录: components, generated, lib)
remotion.config.ts - Remotion webpack/config bootstrap.
package.json - Scaffold-only dependency graph and scripts.
package-lock.json - Locked dependency graph generated by npm install for reproducible scaffold installs.
tsconfig.json - TypeScript compiler contract for the template.
eslint.config.mjs - Flat ESLint entry for scaffold code.
.prettierrc - Formatting baseline for generated templates.
</directory>

<config>
src/AGENTS.md - Local map for the source tree.
src/components/AGENTS.md - Visual primitive and mockup module map.
src/generated/AGENTS.md - URL intake output seam and placeholder generated data map.
src/lib/AGENTS.md - Shared mode/token/font helper map.
</config>

法则: 保持模板可安装、可渲染、可被主线程 orchestrator 直接接管；不把旧协议文件留在这层。
